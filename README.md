# Noorify 🌙

Noorify is a web-based Islamic application designed to provide users with daily Quranic reminders and uplifting messages. The project aims to create a peaceful and meaningful digital experience through a simple and user-friendly interface.

## Features

* Displays daily Quranic verses
* Provides inspirational Islamic reminders
* Clean and responsive user interface
* Simple and easy-to-use design
* Built using HTML, CSS, and JavaScript

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open the `index.html` file in a web browser.
